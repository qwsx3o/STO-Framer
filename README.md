##  Что это такое?

**STO Framer** — это десктопное приложение на Python, которое превращает длинные видео в короткие шортсы за считанные минуты. Никакого монтажа вручную — настраиваешь параметры, запускаешь, получаешь готовый результат.

Простой интерфейс, мощные возможности, открытая архитектура модулей.

---

## ✨ Возможности

### 🎨 Субтитры
- Полная настройка стиля субтитров
- Выбор шрифтов, размеров, цветов и позиций
- Автоматическое распознавание и генерация

### ✂️ Умная обрезка
- Настраиваемая автоматическая нарезка видео
- Гибкие параметры длительности фрагментов
- Интеллектуальное определение интересных моментов

###  Модульная архитектура
- Встроенные модули «из коробки»
- **Напиши свой модуль** — если умеешь программировать, ты можешь расширять функционал под свои задачи
- Открытый API для интеграции

### 🖥️ Простой интерфейс
- Интуитивно понятное GUI-приложение
- Не нужно знать код, чтобы пользоваться
- Настройки сохраняются между сессиями
